# 英単語 よみ・かき・リスニング練習アプリ

HTML / CSS / JavaScript だけで動作する、ローカル利用可能な英単語反復練習アプリです。

## DEMO

https://kubo-4ka.github.io/english_word_practice_app/

## 起動方法

`index.html` をブラウザで開きます。Chrome、Edge、Firefox、Safari などの比較的新しいブラウザを推奨します。
Web サーバは任意で、`file://` でも利用できます。

## 主な機能

- プリセット英単語 865 件 / 32 カテゴリ（「その他」は「あなたの単語」・将来拡張用として保持）
- 読み：英単語 → 日本語四択
- 書き：一文字欠落 / 連続二文字欠落 / 英単語四択
- リスニング：音声 → 英単語四択
- 実験 / スペル特訓（β）：2・3・4 文字の単語をアプリ内 A〜Z キーボードで全文入力
- 通常 / 復習対象 / まだやっていない単語モード
- 「同義語・言い換え優先」「対義語・対になる語優先」を各出題モードと併用可能
- 単語ごとの出題 ON/OFF、挑戦回数、正解、不正解、復習状態
- 「あなたの単語」登録（プリセット以外の利用者登録語）
- 単語一覧検索、カテゴリ・学習状態・同義語有無・対義語有無フィルタ、CSV 出力
- 音声検索（β）：目立たない補助機能として、対応ブラウザのマイク認識結果を検索欄へ入力
- 58 種類のバッジ・実績（通常 55 + シークレット 3）
- 学習データ JSON のエクスポート / 端末間マージインポート
- 5 種類の画面テーマ
- localStorage 保存

## 実験 / スペル特訓（β）

- OS のソフトウェアキーボードではなく、画面内に QWERTY 配列の A〜Z オンスクリーンキーボードを表示します。
- タップ／クリックで英字だけを入力でき、`Aa`で大文字・小文字を切り替えられます。正解判定は大文字・小文字を区別しません。
- 1 文字削除、クリア、答える操作も画面内で完結します。
- PC では補助的に物理キーボードの A〜Z・Backspace・Enter も利用できます。

新しい「実験」タブに、通常の練習とは独立したスペル入力練習を追加しています。出題対象は、現在出題 ON になっている英字だけの 2 文字・3 文字・4 文字の単語です。

- 文字数を 2 / 3 / 4 文字から選択
- 問題数を 5 / 10 / 20 / 30 / 50 問から選択。対象語が少ない場合は、その件数だけ重複なしで出題
- 結果は専用の「スペル特訓履歴」に保存。通常のスコア履歴・単語進捗・復習とは分けて扱う

## 音声検索（β）

単語一覧の検索欄では、キーボード入力に加えてマイクによる音声検索を試せます。β 機能として主張を抑え、必要な人が気になったときに使う補助機能として配置しています。

```text
音声検索 β
↓
英語を話す
↓
ブラウザが音声を文字として認識
↓
検索欄へ認識文字を入力
↓
通常の単語検索を実行
```

例：`fridge` と発音し、ブラウザが `fridge` と認識した場合、検索欄へ `fridge` が入り、そのまま一覧を絞り込みます。

この機能は発音採点ではありません。端末・ブラウザ・マイクがどの文字として認識したかを利用して検索するだけであり、発音の正確さ・発音品質・英語力を評価しません。認識結果が想定した単語と異なる場合もあります。

- `SpeechRecognition` または `webkitSpeechRecognition` を利用できるブラウザのみ対応
- マイク利用許可が必要
- 音声認識方式によってはインターネット接続が必要
- ブラウザや実行方法によっては `file://` では利用できない場合がある
- 非対応環境でも従来のキーボード検索、読み・書き・リスニング等には影響しない
- 音声認識結果はクイズの正誤、復習、バッジ、学習進捗には使用しない

認識言語は、選択中の英語音声の言語・地域が取得できる場合はそれに合わせ、それ以外は `en-US` を使用します。

## 対義語・対になる語

- 対義語・方向の対・対になる動作などを、同義語とは独立した単語 ID 間の関係として登録。
- 38 組の対義語・対になる表現を収録。各単語の挑戦・正解・復習状態は従来どおり ID 単位で独立管理。
- 練習設定に「対義語・対になる語を優先」を追加。通常／復習／未挑戦モードと同時に使用可能。
- 同義語優先と対義語優先を両方 ON にした場合は、どちらかの関係を持つ単語を先に出題し、不足分をその他の対象単語から補完。
- 単語一覧に対義語フィルタと対になる語の表示を追加。検索も対義語を対象にする。
- シークレット実績「対義語マスター」を追加。対象単語を全て挑戦済み、かつ対象の復習 0 件で解禁。
- 対義語は意味の違いを学ぶため、同義語と異なり四択の誤答候補からは除外しない。

## 同義語・言い換えの設計

英語表現はすべて独立した単語として扱います。

例：

```text
p419  refrigerator  冷蔵庫
p758  fridge        冷蔵庫
         ↕ 短縮形
```

`refrigerator` と `fridge` はそれぞれ独立した ID・学習進捗・復習状態を持ちます。
一方で、両者は「短縮形」の関係として関連づけられています。

同様に、関係には次のような種類があります。

- 同義語
- 言い換え
- 短縮形
- 略語
- つづり違い
- 地域差
- 日常表現
- 近い表現

プリセットでは 45 グループ・91 単語が同義語／言い換え関係を持ちます。

この関係は次の用途で使います。

- 単語一覧で関連語を表示
- 「同義語あり」で絞り込み
- 同義語・言い換え優先出題
- 四択で関連語どうしを正解・誤答として同時に並べない
- シークレット実績「同義語マスター」の判定

完全な同義語ではないものの四択で紛らわしすぎる `cook / chef` などは、同義語グループにはせず、誤答候補の衝突回避だけを行います。

## 同義語・言い換え優先

「出題モード」とは独立したチェック設定です。

```text
通常 + 同義語優先
復習対象 + 同義語優先
未挑戦 + 同義語優先
```

のように組み合わせられます。

まず現在の出題対象のうち同義語・言い換え関係を持つ単語を出題し、指定問題数に足りない場合は、そのほかの対象単語で補います。

## あなたの単語（My Words）

「同義語・言い換え」欄へ複数表現を入力した場合も、各表現に独立 ID を発行します。

例：

```text
英単語: refrigerator
日本語: 冷蔵庫
同義語: fridge
```

と登録すると、2 件の独立した単語を作成し、同じ同義語グループとして関連づけます。

## 音声

外部音声 API は使用せず、ブラウザ標準の `speechSynthesis` を利用します。
音声の種類・発音・利用可否は OS、ブラウザ、端末に依存します。

## 保存場所

以下をブラウザの localStorage へ保存します。

- 「あなたの単語」と同義語グループ
- 出題 ON/OFF
- スコア履歴
- スペル特訓履歴（通常実績とは独立）
- 単語ごとの学習進捗・復習状態
- バッジ累計・獲得状況
- 端末間マージ用の端末別累計情報
- 画面テーマ

端末間の引継ぎやバックアップには「履歴」タブの学習データ JSON を使用できます。
