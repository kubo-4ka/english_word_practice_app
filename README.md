# 英単語 よみ・かき・リスニング練習アプリ

HTML / CSS / JavaScript だけで動作する、英単語の反復練習アプリです。
小学生～初級学習者を主な対象として、読む・書く・聞く・復習する流れを繰り返せます。

## DEMO

https://kubo-4ka.github.io/english_word_practice_app/

## 起動方法

`index.html` をブラウザで開いてください。
比較的新しい Chrome / Edge / Firefox / Safari を推奨します。基本機能は `file://` でも利用できます。

## 主な機能

- プリセット英単語 865 語 / 32 カテゴリ
- 読み・書き・リスニングの四択練習
- 通常 / 復習対象 / まだやっていない単語モード
- 同義語・言い換え、対義語・対になる語を利用した優先出題
- 単語ごとの挑戦回数・正解・不正解・復習状態の記録
- 「あなたの単語」の追加
- 単語一覧の検索・絞り込み・CSV 出力
- 今日のランダム英単語
- バッジ・シークレット実績
- 実験 / スペル特訓（β）
- スコア履歴・スペル特訓履歴
- 学習データ JSON のエクスポート / マージインポート
- 5 種類の画面テーマ
- ブラウザ標準の音声読み上げ
- 対応環境での音声検索（β）

## データ保存

学習状況はブラウザの `localStorage` に保存します。
別端末への移行や複数端末の進捗統合には、「履歴」タブの学習データ JSON を利用できます。

画面テーマや利用できる音声は、OS・ブラウザ・端末によって異なります。
音声はブラウザ標準機能による参考音声で、発音の正確さを保証するものではありません。

├─ index.html
├─ style.css

- `app.js`：単語データ、出題、音声、履歴、バッジ、保存処理
